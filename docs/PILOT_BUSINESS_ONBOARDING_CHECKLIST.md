# Pilot Business Onboarding Checklist

## Objetivo

Checklist operativa por negocio antes de marcar GO de piloto.

## Datos base del negocio

- [ ] nombre del negocio validado
- [ ] slug limpio y estable
- [ ] vertical definida
- [ ] responsable comercial asignado
- [ ] responsable tecnico asignado
- [ ] fecha objetivo de apertura definida
- [ ] CTA principal definido

## Identidad y presencia visual

- [ ] descripcion corta entendible
- [ ] ciudad, departamento y direccion revisados
- [ ] telefono de contacto probado
- [ ] foto de perfil visible
- [ ] portada visible
- [ ] sin URLs de media rotas
- [ ] sin placeholders involuntarios en portada o avatar

## Canales de contacto

- [ ] WhatsApp abre al numero correcto
- [ ] sitio web abre correctamente aunque el negocio lo haya escrito sin protocolo
- [ ] Instagram correcto si se mostrara
- [ ] Facebook correcto si se mostrara
- [ ] TikTok correcto si aplica
- [ ] YouTube correcto si aplica
- [ ] Google Maps correcto si aplica

## Catalogo, grupos o menu

- [ ] existe al menos un camino publico con contenido real
- [ ] hay al menos un producto destacado o facil de probar
- [ ] si usa CatalogGroups, el grupo inicial resuelve contenido util
- [ ] si es restaurante, el menu abre en una seccion valida
- [ ] productos sin stock se ven correctos
- [ ] variantes activas tienen precio e imagen coherentes si aplica

## Guia, detalle y CTA

- [ ] la guia aparece si el negocio tiene productos
- [ ] al menos un preset devuelve resultados coherentes
- [ ] "Ver mas opciones" lleva a Productos
- [ ] detalle de producto abre
- [ ] CTA de carrito funciona para al menos un producto si el negocio usara carrito
- [ ] CTA de WhatsApp funciona desde tarjeta o detalle
- [ ] reservas activas solo si el negocio las va a operar
- [ ] encuestas activas solo si el negocio las va a revisar

## Publicaciones y prueba social

- [ ] publicaciones publicas visibles si el negocio las usara
- [ ] testimonios con slug valido
- [ ] multimedia carga sin errores visibles
- [ ] placeholders no rompen layout

## Validacion final

- [ ] recorrido completo probado desde movil
- [ ] negocio sabe que revisar en dia 1, dia 3 y dia 7
- [ ] runbook compartido: [PILOT_RUNBOOK.md](PILOT_RUNBOOK.md)
- [ ] plan compartido: [PILOT_EXECUTION_PLAN.md](PILOT_EXECUTION_PLAN.md)
- [ ] metricas y feedback compartidos: [PILOT_METRICS_AND_FEEDBACK.md](PILOT_METRICS_AND_FEEDBACK.md)

## Resultado

- GO: todos los puntos criticos completos
- NO-GO: existe un blocker en catalogo, guia, CTA, media o links
